# IPO Web Application

A full-stack IPO tracking web application built using HTML, CSS, Bootstrap, JavaScript, Django, Django REST Framework, and SQLite.  
This platform allows users to track upcoming, open, closed, and listed IPOs with complete company details, IPO information, and downloadable documents like RHP and DRHP.

---

## Features

### User Side
- View latest IPO listings
- Dedicated IPO details page
- Track IPO status (Upcoming, Open, Closed, Listed)
- View issue size, price band, listing details, and returns
- Download RHP and DRHP documents

### Admin Side
- Admin dashboard for IPO management
- Add, update, and delete IPO listings
- Manage company profiles and IPO-related documents
- Django Admin Panel integration for dynamic database handling

### Backend Features
- REST API for IPO data using Django REST Framework
- Structured database models for Company, IPO, and Documents
- Real-time data handling using Django Admin and SQLite
- Proper migrations and backend management using Django ORM
