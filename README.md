# IPO Web Application

A full-stack IPO tracking web application built using HTML, CSS, Bootstrap, JavaScript, Django, Django REST Framework, and SQLite.

## Features

- View latest IPO listings
- IPO details page
- Admin dashboard for IPO management
- Django Admin Panel
- REST API for IPO data
- Company, IPO, and Document database models

## Tech Stack

### Frontend
- HTML
- CSS
- Bootstrap 5
- JavaScript

### Backend
- Python
- Django
- Django REST Framework

### Database
- SQLite

### Version Control
- Git + GitHub
